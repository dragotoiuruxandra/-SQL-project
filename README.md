
The database contains the following tables:
- `membrii` – gym members
- `antrenori` – trainers
- `cursuri` – courses
- `abonamente` – subscriptions
- `plati` – payments

SQL Concepts Implemented

- Table creation and relational database design
- Primary and foreign keys
- Data validation using `CHECK` and `NOT NULL` constraints
- Data insertion and updates
- Filtering and sorting data
- Aggregate functions (`SUM`, `AVG`)
- `GROUP BY`
- Indexes
- Date handling and data conversion
- Table relationships and foreign key constraints
